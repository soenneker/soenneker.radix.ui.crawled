Examples

Responsive

All props marked Responsive, such as columns and rows accept a breakpoint object. For example, the following grid starts with 1 column, and uses 2 columns from the medium breakpoint.

																	Grid
																
																columns
																
																	=
																	{
																	{
																	initial
																	:
																	"1"
																	,
																	md
																	:
																	"2"
																	}
																	}
																
																gap
																
																	=
																	"3"
																
																width
																
																	=
																	"auto"
																
																>
