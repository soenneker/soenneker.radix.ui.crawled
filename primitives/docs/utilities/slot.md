		<pre style="word-wrap: break-word; white-space: pre-wrap;"># Slot  Merges its props onto its immediate child.  ## Features  - Can be used to support your own \`asChild\` prop.  ## [Anatomy](#anatomy)  Import the component.  ```jsx import { Slot } from "radix-ui";  export default () =&gt; (   &lt;Slot.Root&gt;     &lt;div&gt;Hello&lt;/div&gt;   &lt;/Slot.Root&gt; ); ```  ## [Basic example](#basic-example)  Use to create your own `asChild` API.  When your component has a single children element:  ```jsx // your-button.jsx  import * as React from "react";  import { Slot } from "radix-ui";  function Button({ asChild, ...props }) {   const Comp = asChild ? Slot.Root : "button";    return &lt;Comp {...props} /&gt;; } ```  Use `Slottable` when your component has multiple children to pass the props to the correct element:  ```jsx // your-button.jsx  import * as React from "react";  import { Slot } from "radix-ui";  function Button({ asChild, children, leftElement, rightElement, ...props }) {   const Comp = asChild ? Slot.Root : "button";    return (     &lt;Comp {...props}&gt;       {leftElement}        &lt;Slot.Slottable&gt;{children}&lt;/Slot.Slottable&gt;        {rightElement}     &lt;/Comp&gt;   ); } ```  ### [Wrapping the slotted element](#wrapping-the-slotted-element)  Pass the child to `Slottable` via the `child` prop and provide a render function to wrap the slotted element in additional markup, while `Slot` still merges its props and refs onto the child.  ```jsx // your-button.jsx  import * as React from "react";  import { Slot } from "radix-ui";  function Button({ asChild, children, ...props }) {   const Comp = asChild ? Slot.Root : "button";    return (     &lt;Comp {...props}&gt;       &lt;Slot.Slottable child={children}&gt;         {(child) =&gt; &lt;span className="ButtonInner"&gt;{child}&lt;/span&gt;}       &lt;/Slot.Slottable&gt;     &lt;/Comp&gt;   ); } ```  ### [Usage](#usage)  ```jsx import { Button } from "./your-button";  export default () =&gt; (   &lt;Button asChild&gt;     &lt;a href="/contact"&gt;Contact&lt;/a&gt;   &lt;/Button&gt; ); ```  ### [Event handlers](#event-handlers)  Any prop that starts with `on` (e.g., `onClick`) is considered an event handler.  When merging event handlers, `Slot` will create a new function where the child handler takes precedence over the slot handler.  If one of the event handlers relies on `event.defaultPrevented` make sure that the order is correct.  ```jsx import { Slot } from "radix-ui";  export default () =&gt; (   &lt;Slot.Root     onClick={(event) =&gt; {       if (!event.defaultPrevented) console.log("Not logged because default is prevented.");     }}   &gt;     &lt;button onClick={(event) =&gt; event.preventDefault()} /&gt;   &lt;/Slot.Root&gt; ); ```  ### [Typed slots](#typed-slots)  `Slot.createSlot` returns a `Slot` component scoped to the name you pass, which is used in its error messages. It accepts type arguments to specify the element the slot renders and the props it accepts, so consumers get accurate types. `Slot.SlotProps` accepts the same type arguments.  ```tsx import * as React from "react";  import { Slot } from "radix-ui";  type ButtonProps = React.ComponentPropsWithoutRef&lt;"button"&gt; &amp; {   variant?: "solid" | "ghost"; };  const ButtonSlot = Slot.createSlot&lt;HTMLButtonElement, ButtonProps&gt;("Button.Slot"); ```  &lt;!--$--&gt;  &lt;!--/$--&gt;
